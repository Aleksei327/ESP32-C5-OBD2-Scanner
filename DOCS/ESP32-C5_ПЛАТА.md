# Плата Seeed XIAO ESP32-C5

Мозг адаптера. Берём на [Gotronic](https://www.gotronic.fr/art-carte-xiao-esp32-c5-100010048-49303.htm), код 100010048, 6,90 €. Размер 21 × 17,8 мм.

## Характеристики

| Параметр | Значение |
| --- | --- |
| Чип | ESP32-C5HR8: RISC-V 240 МГц, 384 КБ ОЗУ + 8 МБ PSRAM в корпусе |
| Флеш | 8 МБ |
| Радио | Wi-Fi 6 2,4 + 5 ГГц, Bluetooth 5 (BLE), Zigbee/Thread |
| CAN | 2 контроллера TWAI, оба с CAN-FD |
| Антенна | внешняя, разъём U.FL, антенна в комплекте |
| USB | USB-C, встроенный USB Serial/JTAG: прошивка и консоль по одному кабелю |
| Ножки | 11 штук (D0–D10), шаг 2,54 мм |
| Прочее | заряд LiPo (не используем), кнопки RST и BOOT |

## Распиновка (по вики Seeed)

| Ножка | GPIO | Особенность | На плате v1 |
| --- | --- | --- | --- |
| D0 | GPIO1 | единственная ножка с АЦП на гребёнке | **напряжение АКБ** |
| D1 | GPIO0 | — | **CAN-B RX** |
| D2 | GPIO25 | strapping | не занимаем |
| D3 | GPIO7 | strapping | не занимаем |
| D4 | GPIO23 | I2C SDA | **Rs канала A** («только слушать») |
| D5 | GPIO24 | I2C SCL | **Rs канала B** («только слушать») |
| D6 | GPIO11 | UART0 TX, при загрузке сюда идёт служебный лог | **не для CAN** |
| D7 | GPIO12 | UART0 RX | резерв |
| D8 | GPIO8 | — | **CAN-B TX** |
| D9 | GPIO9 | — | **CAN-A RX** |
| D10 | GPIO10 | — | **CAN-A TX** |
| 5V | VBUS | линия USB, «вход/выход» | питание от нашего DC-DC |
| 3V3 | выход стабилизатора | | питание трансиверов CAN |
| GND | | | |

Внутри платы, на гребёнку не выведены: светодиод GPIO27, кнопка BOOT на GPIO28, замер батареи (GPIO6 и GPIO26), площадки JTAG снизу (GPIO2–5) — их не трогаем.

**Strapping-выводы.** Их уровень чип считывает в момент включения. Сигналы, которые сами задают уровень при включении (например, выход приёмника CAN), на D2 и D3 не вешаем.

**D6 (GPIO11).** При загрузке чип пишет туда служебный лог. Если подключить туда CAN TX, этот лог мусором уйдёт в шину машины.

**Подтяжки.** На Rs трансиверов (D4 и D5) и на CAN TX (D10 и D8) ставим по 10 кОм к 3,3 В. Пока ESP32 загружается или перепрошивается, выводами никто не управляет, а подтяжки держат трансиверы в режиме «только слушать», и в машину ничего не уйдёт. Подробнее — в [CAN_SN65HVD230](CAN_SN65HVD230.md).

**Питание через вывод 5V.** Это линия USB, и есть ли на ней свой диод, по вики непонятно. Поэтому наш DC-DC даёт на этот вывод ~4,6 В, чуть меньше, чем USB. Если при питании от машины воткнуть ноутбук, в ноутбук ничего не пойдёт. Подробнее — в [DC-DC_5V](DC-DC_5V.md).
