# Удалённый помощник

[English version](README.md)

Машина на парковке, компьютер дома. Телефон у машины соединяет адаптер с компьютером через мобильный интернет, и программа на компьютере (например, Claude Code) работает с адаптером так, будто он рядом.

```text
адаптер ──Wi-Fi── телефон ──мобильный интернет── Cloudflare ── relay.py (дома) ── adapter.py / помощник
```

- **Телефон**: приложение подключается к адаптеру через его Wi-Fi, а к компьютеру — через мобильные данные. Интернет на телефоне при этом работает: адаптер не выдаёт себя за шлюз, и Android оставляет интернет на мобильной сети.
- **Компьютер**: `relay.py` — посредник на `127.0.0.1:8790`. Снаружи до него можно достучаться через бесплатный туннель Cloudflare (`cloudflared`, без аккаунта); входящие подключения к компьютеру не нужны, хватит любого интернета, даже раздачи с телефона.
- **Ключ** создаётся заново при каждом запуске `relay.py`. Без него к посреднику не подключиться. Адрес туннеля тоже каждый раз новый.

## Как запустить

1. На компьютере:

   ```sh
   python remote/relay.py
   ```

   Скрипт сам запускает `cloudflared` и печатает **АДРЕС ДЛЯ ТЕЛЕФОНА** вида `wss://….trycloudflare.com/phone?key=…`. Адрес и ключ пишутся в `remote/.session.json` (в git не попадает).

   `cloudflared` — один файл: [страница загрузки Cloudflare](https://github.com/cloudflare/cloudflared/releases), `cloudflared-windows-amd64.exe` положить в `%LOCALAPPDATA%\cloudflared\cloudflared.exe`, либо `winget install Cloudflare.cloudflared`.

2. На телефоне: подключиться к Wi-Fi адаптера, в приложении — «Подключить адаптер», потом Настройки → **Удалённый помощник**: вставить адрес и нажать «Включить». Пока помощник подключён, сверху на всех экранах зелёная полоска с кнопкой выключения, экран не гаснет.

3. На компьютере — команды адаптеру:

   ```sh
   python remote/adapter.py hello
   python remote/adapter.py open B
   python remote/adapter.py req B 752 652 10C0 2180 17FF00
   python remote/adapter.py monitor B 5
   ```

   `--url ws://192.168.4.1:81/ws` — напрямую к адаптеру, `--url ws://127.0.0.1:8765` — к симулятору.

`adapter.py` шлёт только запросы на чтение (и сброс ошибок): сервисы, которые что-то меняют в блоках, он не отправляет.

## Задержки

Один запрос туда и обратно через туннель и мобильную сеть — около 0,2 с (`hello` — 170–300 мс при проверке через мобильный интернет). Для чтения ошибок и данных этого хватает; автоскан идёт медленнее, чем рядом с машиной.
