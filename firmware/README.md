# Прошивка

## scaner_fw — самотест платы v1

Первая прошивка нужна, чтобы проверить железо: оба канала CAN, режим «только слушать» и замер напряжения АКБ. Консоль работает по USB-разъёму XIAO.

| Команда | Что делает |
| --- | --- |
| `selftest` | каналы A и B соединены проводами (CANH–CANH, CANL–CANL), JP2 и JP3 замкнуты; каждый канал шлёт другому 20 кадров |
| `listen [секунды]` | слушает оба канала и печатает кадры. Трансиверы в режиме «только слушать» (Rs = 1), контроллеры CAN в listen-only: в машину не уходит ничего |
| `vbat` | напряжение АКБ (пин 16 OBD) |
| `status` | состояние каналов, счётчики ошибок, АКБ |

При включении оба трансивера сразу переводятся в «только слушать», а передача разрешается только на время `selftest`.

## Сборка

Нужен ESP-IDF 6.1 (ESP32-C5 поддерживается начиная с 5.5). В VS Code — расширение ESP-IDF от Espressif, в нём указать уже установленный ESP-IDF.

> ⚠ Путь к проекту — только латиница и без пробелов: с кириллицей (например, «Документы») ESP-IDF и компилятор GCC не работают. Поэтому проект лежит в `D:\scaner-auto`. На этом компьютере ESP-IDF стоит в `D:\esp\v6.1\esp-idf`, инструменты — в `D:\esp\.espressif`.

```text
idf.py set-target esp32c5
idf.py build
idf.py -p COMx flash monitor
```
