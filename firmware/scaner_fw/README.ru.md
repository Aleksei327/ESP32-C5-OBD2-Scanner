# Прошивка самотеста платы

[English version](README.md)

Прошивка на ESP-IDF 6.1 для XIAO ESP32-C5 на плате v1. Проверяет железо, пока не написана настоящая прошивка адаптера (сервер WebSocket для приложения). Консоль — по встроенному в XIAO USB Serial/JTAG.

| Команда | Что делает |
| --- | --- |
| `selftest` | Каналы A и B соединены проводами, JP2/JP3 замкнуты: гоняет кадры A→B и B→A и пишет результат |
| `listen [секунды]` | Слушает оба канала, ничего не передавая (Rs = 1, контроллеры в listen-only) |
| `vbat` | Напряжение АКБ с делителя на D0 |
| `status` | Состояние каналов и АКБ |

Ножки — в [`main/board.h`](main/board.h). Подтяжек на входах D трансиверов на плате нет: прошивка держит TX в 1 как GPIO, пока его не заберёт контроллер CAN, и опускает Rs только после запуска контроллера.

## Сборка

```sh
idf.py set-target esp32c5   # один раз
idf.py build flash monitor
```
