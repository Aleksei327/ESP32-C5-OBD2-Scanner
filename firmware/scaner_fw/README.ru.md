# Прошивка адаптера

[English version](README.md)

Прошивка на ESP-IDF 6.1 для XIAO ESP32-C5 на плате v1. Адаптер поднимает свою сеть Wi-Fi и ждёт приложение на `ws://192.168.4.1:81/ws`; протокол — [DOCS/ПРОТОКОЛ.md](../../DOCS/ПРОТОКОЛ.md), тот же, что у симулятора. Консоль — по встроенному в XIAO USB Serial/JTAG.

## Wi-Fi

Сеть `SCANER-C5-XXXX` (XXXX — конец MAC-адреса), WPA2. Пароль — 10 случайных символов, создаётся при первом включении и хранится в NVS. Посмотреть или сменить — командой `wifi` в консоли. Адрес адаптера — 192.168.4.1, телефон получает адрес по DHCP.

## Консоль

| Команда | Что делает |
| --- | --- |
| `status` | Состояние шин, Wi-Fi, памяти и АКБ |
| `wifi` | Имя сети, пароль, сколько телефонов в сети и приложений подключено |
| `wifi pass <пароль>` | Сменить пароль (8–63 символа) |
| `vbat` | Напряжение АКБ с делителя на D0 |
| `listen [секунды]` | Печатать кадры обеих шин, ничего не передавая (Rs = 1, контроллеры в listen-only) |
| `selftest` | Каналы A и B соединены проводами, JP2/JP3 замкнуты: гоняет кадры A→B и B→A. Только когда приложение не подключено |

## Как устроено

| Файл | Что делает |
| --- | --- |
| `main/main.c` | Запуск и консоль |
| `main/wifi_ap.c` | Точка доступа, пароль в NVS |
| `main/ws_server.c` | WebSocket-сервер (`esp_http_server`), список подключённых приложений, отправка из любой задачи |
| `main/proto.c` | Команды приложения; на каждую шину — очередь команд, задача приёма кадров и задача обмена (ISO-TP, «я здесь»); сводка монитора и напряжение раз в 250 мс / 1 с |
| `main/can_ch.c` | Канал CAN: контроллер TWAI и трансивер с управлением Rs |
| `main/vbat.c` | Напряжение АКБ |

Ножки — в [`main/board.h`](main/board.h). Подтяжек на входах D трансиверов на плате нет: прошивка держит TX в 1 как GPIO, пока его не заберёт контроллер CAN, и опускает Rs только после запуска контроллера. После включения обе шины закрыты; когда приложение отключается, адаптер закрывает их сам.

## Сборка

```sh
idf.py set-target esp32c5   # один раз
idf.py build flash monitor
```

JSON разбирает библиотека cJSON: в ESP-IDF 6 она не входит, `idf.py` скачивает её сам при первой сборке (компонент `espressif/cjson`, нужен интернет; версия закреплена в `dependencies.lock`).
